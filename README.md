# MESP AI

Modular Evaluation and Smart Positioning AI

## Overview

MESP AI is a professional Pine Script v6 trading framework designed for
multi-factor decision making using weighted scoring.

## Features

- Trend Engine
- Market Structure Engine
- Momentum Engine
- Volume Engine
- Volatility Engine
- Session Engine
- Decision Engine
- Risk Manager
- Dashboard
- Smart Alerts
